# 模型侧下一阶段实验计划

本计划从首个里程碑的 `mock-validated` 状态推进到可复现零样本基线。未经当前阶段退出门槛，不扩大数据量、不启动正式 QLoRA。

## 阶段 0：环境与权重登记

目标：让一次真实推理可追踪且不会隐式漂移。

1. 根环境锁定 Python、MLX、MLX-VLM、Pydantic 与 Pillow 版本；
2. 按许可证流程取得 `mlx-community/Qwen3-VL-2B-Instruct-4bit`；
3. 使用已固定 revision `9c4f5209e57b31f4b9dfba735de3fb983739c9cc`；
4. 计算本地 safetensors SHA-256，登记绝对缓存路径与磁盘占用；
5. 复制模型配置并填写 `local_model_path`，保持 `allow_download=false` 与 `trust_remote_code=false`。

退出门槛：配置可加载；权重、revision、哈希和许可证记录完整；启动不会联网。

## 阶段 1：M5/16GB 最小真实探针

固定三个自有或合成图片用例：明确违规、明确合规、证据不足。每个用例连续执行 3 次，记录：

- 冷启动、首轮和热推理耗时；
- 进程峰值内存与系统交换量；
- 原始输出、解析结果、配置指纹和随机种子；
- JSON 是否有效、框是否为原图像素且越界；
- 三次输出是否完全一致；
- 拒答用例是否返回 `uncertain` 和明确拒答码。

资源止损线：首次 OOM、持续高交换、单次生成超过 30 秒或机身热降频明显时立即停止放量。依次降低图像像素上限和输出 token；每次调整必须形成新配置指纹。

退出门槛：3 类用例全部完成；无 OOM；异常可诊断；重复输出差异有记录。

## 阶段 2：零样本冻结基线

在数据侧冻结的小回归集上运行 Qwen3-VL 4-bit 零样本。至少包含中英文、正例、普通负例、困难负例、小目标、遮挡、模糊和文本干扰切片。

输出：逐样本预测、配置/权重指纹、Macro-F1、Acc@IoU 0.5、Schema 有效率、困难负例假阳性率、拒答率、P50/P95 延迟和峰值内存。失败案例按漏检、误检、定位、格式、解释冲突和数据问题分类。

退出门槛：零样本结果可用同一命令复现；测试样本无人工挑选；失败清单完整。

## 阶段 3：精度与资源消融

保持数据、提示、预处理、硬件和测量方法不变，比较：

1. 4-bit 与可行的 8-bit/FP16；
2. 至少两档输入分辨率；
3. 输出上限 256 与 512；
4. 固定 seed 的两次独立运行。

MVP 目标仍按需求基线：M5 4-bit P95 不高于 8 秒、峰值统一内存不高于 12GB、100 请求无 OOM。探针未达标时不得宣称部署验收通过。

## 阶段 4：QLoRA 最小训练探针

只在真实推理与零样本基线稳定后启动。首轮使用 batch 1、gradient accumulation 16、gradient checkpointing，并限制为小样本和少量 step。

预注册矩阵：

| 变量 | 取值 |
|---|---|
| rank | 8、16 |
| 模块策略 | language-only、vision-language |
| 困难负样本 | 无、有 |
| seed | 至少 2 个固定 seed |

每个 run 必须记录 run_id、数据版本、基础权重哈希、适配器哈希、峰值内存、耗时、最佳验证 checkpoint 和停止原因。先证明最小反向传播可运行，再扩大步数。

## 阶段 5：专用模型协同

分别实现 `Florence2Adapter` 和 `RFDETRAdapter`，先作为独立基线，不直接融合。取得同一测试集的定位结果后，预注册冲突规则：

- VLM 无证据、specialist 有高置信证据；
- VLM 与 specialist 框不重叠；
- 两者低置信或结论冲突；
- specialist 未就绪或超时。

融合必须通过现有 `FusionPolicy` 返回来源可追踪结果；冲突默认拒答/人工复核，不用任一模型强行覆盖另一模型。
