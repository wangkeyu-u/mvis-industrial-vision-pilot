# Qwen3-VL-2B-Instruct 4-bit 候选模型卡（M1）

## 基本信息

| 字段 | 值 |
|---|---|
| 状态 | candidate / integration-only |
| 原始模型 | `Qwen/Qwen3-VL-2B-Instruct` |
| MLX 候选 | `mlx-community/Qwen3-VL-2B-Instruct-4bit` |
| MLX revision | `9c4f5209e57b31f4b9dfba735de3fb983739c9cc` |
| 量化 | 4-bit，group size 64，affine（待本地权重配置复核） |
| 目标设备 | M5 MacBook Air / 16GB |
| 领域 | 视觉合规审查 |
| 适配器 | 无；QLoRA 接口已预留 |
| 许可证 | 候选仓库标记 Apache-2.0；发布前仍需独立许可检查 |

## 预期用途

单张 JPG/PNG/WEBP 经上游安全解码后，对中英文合规查询执行判断、视觉定位、简短解释和结构化抽取。结果仅作辅助分析；低置信度或证据不足必须转人工复核。

## 禁止用途

- 医疗、执法、金融授信等高风险自动决策；
- 无人工复核的自动处罚或下架；
- 将模型解释视为事实来源；
- 绕过上游图片签名、像素数和隐私校验；
- 在未登记来源与哈希的情况下加载任意 checkpoint。

## 输入输出

输入由 `ModelRequest` 表示：单图、原始宽高、1-1000 字符查询、任务类型和可选生成参数。输出由 `ModelResult` 表示：`Decision`、证据对象、原图像素框、置信度、原因、拒答信号与模型溯源。

默认生成参数为：seed `20260808`、`do_sample=false`、temperature `0.0`、top-p `1.0`、max tokens `512`。MLX 后端会串行执行“设置种子 + 生成”，以避免并发请求争用全局随机状态。这提供确定性执行意图；真实 MLX 运行仍需重复实验验证数值与算子层面的一致性。

## 已知限制

- M1 只完成 mock 适配器验证，没有真实模型效果与性能数据；
- Qwen 输出仍可能产生无效 JSON、错误框或过度自信；严格解析只能拒绝坏结果，不能提升视觉能力；
- 提示词不能替代困难负样本训练、冻结测试集和正式幻觉评测；
- 量化可能损失定位精度，必须与 FP16/8-bit 公平对比；
- specialist 和 QLoRA 当前是接口，不是已完成能力；
- 本地权重哈希、依赖锁文件、MLX 版本和许可证证据仍待登记。

## 发布前最低验证

1. 固定本地权重 SHA-256 与 MLX/MLX-VLM 版本；
2. 运行单图探针并记录冷启动、热启动和峰值统一内存；
3. 在冻结回归集验证 JSON、像素框、拒答和中英文查询；
4. 完成 100 请求无 OOM 稳定性测试；
5. 产出零样本正式指标后，才允许把本卡状态提升为 `validated`。
